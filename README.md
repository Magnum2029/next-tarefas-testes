# 📋 Lista de Tarefas - Testes Unitários em Next.js

Projeto desenvolvido como atividade da **IBAC** utilizando **Next.js (App Router)**, **TypeScript**, **Jest** e **Testing Library**.

## Tecnologias

* Next.js 15 (App Router)
* React
* TypeScript
* Jest
* Testing Library

## Funcionalidades

* Listagem de tarefas carregada por um Server Component.
* Adição de novas tarefas por um Client Component.
* Hook personalizado para contar tarefas.
* Testes unitários dos componentes, hook e renderização da página.

## Como executar o projeto

```bash
npm install
npm run dev
```

Acesse: `http://localhost:3000`
